# 第3步参考素材卡片排版设计

## 目标

优化微信小程序第3步“添加参考素材”的人脸参考卡片和穿搭参考卡片，在不改变现有数据与操作逻辑的前提下，让界面更干净、按钮不再竖向堆叠，并扩大备注输入区域。

## 最终确认方案

1. 参考图片固定显示在卡片左侧。
2. 不再显示本地文件名。
3. 人脸参考卡片的“主参考/设为主参考”和“删除”按钮在同一行显示。
4. 穿搭参考卡片先显示目标选择项，再将“衣物”“配饰”“删除”三个按钮等宽放在同一行。
5. 人脸备注和穿搭备注移动到卡片底部，横跨整张卡片可用宽度。
6. 备注输入控件改为两行高度的 `textarea`，允许页面适当变长。
7. 人脸、穿搭操作按钮统一高度、字号、圆角、间距和文字垂直居中效果。
8. 缩小无意义的上下留白，但保留足够点击区域。
9. 小屏手机上图片区域保持固定宽度，右侧操作区使用剩余空间；按钮文字不得换行或溢出。

## 布局结构

### 人脸参考卡片

```text
┌────────────────────────────┐
│ [图片]  [主参考/设为主参考] [删除] │
│ 备注输入框（横跨整张卡片）       │
│ 备注输入框第二行                 │
└────────────────────────────┘
```

### 穿搭参考卡片

```text
┌────────────────────────────┐
│ [图片]  目标：整套穿搭           │
│         [衣物] [配饰] [删除]     │
│ 备注输入框（横跨整张卡片）       │
│ 备注输入框第二行                 │
└────────────────────────────┘
```

## 兼容要求

- 保持 `setPrimaryFace`、`removeFace`、`onWardrobeTargetInput`、`onWardrobeKindChange`、`removeWardrobe`、`onFaceNoteInput` 和 `onWardrobeNoteInput` 的现有调用参数不变。
- 保持人脸参考、穿搭参考的存储结构不变。
- 不影响其他步骤、历史记录、主图、红圈、提示词和生成参数。
- 使用微信小程序基础组件和普通 WXSS，不引入第三方组件。
- 基础库按稳定版 `3.16.2` 验证。

## 验收标准

- 文件名不再出现在参考卡片中。
- 人脸卡片两个按钮始终同一行。
- 穿搭卡片三个按钮始终同一行且等宽。
- 两个备注框均可显示约两行文字，并横跨卡片底部。
- 320px 左右的小屏宽度下不出现按钮换行、横向滚动或卡片溢出。
- 所有原有点击、选择、删除和输入功能正常。
