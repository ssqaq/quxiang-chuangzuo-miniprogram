# 工作台三张功能卡片底部留白设计

## 目标

将工作台首页三张功能卡片中，说明文字最后一行到底部内边缘的视觉留白统一为约 16px，并恢复功能说明到第一张卡片、三张卡片之间原有的响应式外部间距，不改变卡片文案、图标、点击反馈和跳转逻辑。

## 范围

只调整 `pages/workbench/workbench.wxss`。目标卡片为：

- `entry-card-custom`：开始新创作；
- `recent-card`：制作记录空状态；
- `publish-export-entry`：降低 AI 识别率再导出照片。

## 实现方案

保留现有横向布局，在三张卡片的共同样式中设置统一的顶部和底部内边距；“开始新创作”卡片收窄为 `130rpx`，裁掉多余底部高度，图标贴顶部、文字组使用 0.10.21 的顶部基线和 `18rpx` 内部上间距，同时保留约 `24rpx` 底部留白。其他卡片保持原有高度和间距规则。制作记录空状态的文案继续放在标题下面，不改 WXML 结构。

## 验收标准

1. 三张卡片说明文字到底边的视觉留白均约 16px，允许 1–2px 的字体抗锯齿误差。
2. 三张卡片的图标、标题、说明文字仍完整显示，不溢出、不重叠。
3. 功能说明到第一张卡片、卡片之间保持原有响应式外部间距。
4. 现有静态校验通过。
5. 版本号升一个 patch 版本并生成正式发布包。
