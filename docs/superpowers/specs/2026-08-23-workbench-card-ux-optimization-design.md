# 首页卡片体验优化设计

## 1. 目标

本次只调整创作工作台首页，不改变制作页、制作记录数据、云函数和图片处理流程。

需要完成：

1. 删除“制作记录”空状态区域里重复的“小记”图标；
2. 缩短首页功能卡片的跳转等待；
3. 让卡片按下时立即出现明确反馈；
4. 把空制作记录提示改成用户一眼能看懂的话；
5. 统一首页入口卡片的基础高度。

## 2. 已确认方案

采用用户确认的方案 A：

- “制作记录”标题左侧原有主图标保留；
- 删除空状态第二行里重复的“小记”图标；
- 空状态不再单独占一整行，提示文字移到“制作记录”标题下面；
- 存在制作记录时，继续显示最新一张记录，不删除现有预览功能；
- 没有制作记录时，制作记录卡片与另外两个功能入口保持统一高度；
- 存在最新记录时，制作记录卡片允许按内容自然加高。

## 3. 页面显示

### 3.1 空制作记录

空状态文案固定为：

```text
还没有制作记录，完成一张照片后会显示在这里。
```

文案显示在“制作记录”标题下面，与“开始新创作”和“去AI标识再导出照片”的说明文字使用同一层级。

### 3.2 有制作记录

- 保留“最近产出 / 制作记录”标题；
- 保留最新一张照片、项目名、时间和预览功能；
- 保留“查看全部”按钮；
- 只显示一条最新记录，不改变记录页的完整列表。

### 3.3 卡片高度

以下三个首页入口使用统一基础高度：

- 开始新创作；
- 没有记录时的制作记录；
- 去AI标识再导出照片。

统一基础高度为 `148rpx`，并统一使用 `box-sizing: border-box`。有最新记录的制作记录卡片可以自然加高，避免压缩图片和文字。

## 4. 跳转速度

工作台跳转改为直接调用 `wx.navigateTo`：

- 删除跳转前的 `wx.showLoading`；
- 删除为跳转锁调用 `setData` 导致的页面刷新；
- 使用页面实例字段保存跳转锁，避免重复点击产生多个页面；
- 跳转失败时立即解锁并显示对应提示；
- 页面重新显示时重置跳转锁。

原有草稿确认弹窗保留，避免用户误清除未完成内容。

## 5. 按下反馈

三个首页功能卡片统一设置：

- `hover-start-time="0"`，按下立即反馈；
- `hover-stay-time="70"`，松手后快速恢复；
- 按下时轻微缩小到 `0.985`；
- 透明度调整为 `0.92`；
- 阴影同步减弱；
- 动画时长缩短到约 `0.08s`。

系统开启减少动效时，不执行缩放。

## 6. 数据和兼容性

- 不删除或修改制作记录数据；
- 不删除或修改草稿数据；
- 不改变 `storage.loadRecords()` 返回格式；
- 不改变制作记录页；
- 不使用 WXSS 通配相邻选择器；
- 小屏和大屏继续沿用现有间距规则。

## 8. 验收标准

1. 首页空制作记录区域不再出现第二个“小记”图标；
2. 空状态文案完整显示为指定内容；
3. 空状态提示位于“制作记录”标题下面；
4. 有最新记录时仍能显示和预览；
5. 三个首页入口的基础高度一致；
6. 按下任意入口卡片都会立即出现反馈；
7. 无草稿时点击“开始新创作”不再出现加载遮罩；
8. 制作记录和导出入口使用同一套快速跳转锁；
9. 连续快速点击不会重复打开多个页面；
10. 静态检查、图片检查、手势检查和兼容性检查全部通过；
11. 版本从 `0.8.7` 升级到 `0.9.0`；
12. 生成 `wechat-miniapp-release-v0.9.0.zip` 正式发布包。
