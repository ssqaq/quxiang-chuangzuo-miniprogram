# 管理员运行监控区块顺序调整设计

## 目标

调整管理员页运行监控区域的视觉顺序：

1. “系统运行概览”继续紧跟在“运行监控”标题下面；
2. “用户端日志”放在“部署与探针”前面；
3. “部署与探针”紧跟在“用户端日志”卡片后面；
4. “失败情况”及其统计功能保持原位置和行为不变。

## 实现范围

- 只调整 `pages/admin/admin.wxml` 中两个完整区块的顺序。
- 不修改 `admin.js`、云函数、数据库、接口、数据字段或折叠状态逻辑。
- 保留现有按钮、刷新、展开/收起、跳转和日志详情功能。

## 验收标准

- 页面顺序为：运行监控 → 系统运行概览 → 用户端日志 → 部署与探针 → 失败情况。
- 用户端日志仍可刷新、展开、筛选、加载更多和查看详情。
- 部署与探针仍可展开，内部部署信息、探针、历史和部署日志不丢失。
- 失败情况仍可选月份、导出和查看详情。
- WXML/JS 静态检查及管理员页 smoke 检查通过。
