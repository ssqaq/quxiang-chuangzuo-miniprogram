# 清除主图与红圈绘制性能优化设计

## 目标

- 仅在第 1 步和第 2 步，将“清除主图”放在“重新选择主图”右侧；
- 两个按钮使用完全一致的蓝色底、字号、高度、圆角和垂直居中规则；
- 清除主图时移除主图、红圈、mask、图片分析和当前提示词；
- 保留人脸参考图、穿搭参考图、其他后续参数和历史记录；
- 降低真机拖动红圈时的卡顿。

## 清除范围

清除以下字段：

- `mainImage`
- `maskCircle`
- `maskFileID`
- `sceneDescription`
- `poseDescription`
- `faceDirectionDescription`
- `lightingMakeupDescription`
- `promptDraft`
- `negativePrompt`

保留参考素材、授权状态、自定义锁定要求、生成结果和历史记录。执行前显示确认框，防止误触。

## 绘制优化

当前实现每次 `touchmove` 都把整张主图重新绘制到 Canvas。新实现采用两层结构：

1. 底层普通 `image` 显示主图；
2. 顶层透明 Canvas 只清理并绘制红圈；
3. 拖动事件以约 30 FPS 合并刷新；
4. 触摸 Canvas 时阻止页面跟随滚动；
5. 手指抬起时立即绘制最终红圈并持久化。

这样避免重复解码和绘制大图，同时继续使用兼容性较好的旧版 Canvas API。

## 验证

- 静态检查确认按钮位置、清除方法和分层结构存在；
- 静态检查确认可见 Canvas 不再调用 `drawImage`；
- 执行现有兼容、图片和部署检查；
- 开发者工具检查按钮布局和清除结果；
- 真机检查拖动流畅度、页面不会跟随滚动、最终红圈位置正确。
