# 首页入口箭头与进入动画设计

## 1. 目标

本次只调整创作工作台首页的右侧操作区和页面进入效果，不改变入口顺序、制作记录预览、草稿处理、跳转地址或业务数据。

需要完成：

1. 统一三个首页功能卡片右侧操作区；
2. 保留制作记录的“查看全部”文字；
3. 增加轻量、快速且不阻塞点击的页面进入动画。

## 2. 已确认方案

采用用户确认的方案 A：

- “开始新创作”使用统一入口箭头；
- “制作记录”保留“查看全部”，并在文字后增加同款箭头；
- “去AI标识再导出照片”使用统一入口箭头；
- 最新制作记录预览里的小箭头继续保留，它只表示预览单张记录；
- 首页主体使用一次 `180ms` 的淡入上移动画；
- 不给三张卡片增加依次出现的等待时间。

## 3. 统一右侧操作区

### 3.1 开始新创作和导出入口

两个入口使用相同的箭头基础样式：

- 字符：`›`
- 字号：`36rpx`
- 行高：`1`
- 距离卡片右边：`18rpx`
- 垂直位置：卡片正中

颜色可以继续跟随各自卡片的主题色，但尺寸和位置必须一致。

### 3.2 制作记录

“查看全部”按钮继续保留，结构调整为：

```text
查看全部  ›
```

要求：

- 文字和箭头在同一行；
- 箭头使用与另外两个入口相同的字号和行高；
- 整个按钮的最右侧与另外两个入口箭头使用同一右边基线；
- 点击文字或箭头都进入制作记录页；
- 不增加额外的独立跳转按钮。

### 3.3 最新记录预览

最新记录列表里的箭头保留现状，不套用首页入口操作区位置。它仍然表示点击后预览该张图片。

## 4. 页面进入动画

首页主体使用一次轻量动画：

- 动画时长：`180ms`
- 透明度：从 `0` 到 `1`
- 垂直位移：从 `8rpx` 到 `0`
- 缓动：`ease-out`
- 不设置延迟；
- 不禁用点击；
- 不通过 JavaScript 定时器控制；
- 不触发页面数据刷新；
- 不启动人脸模型。

动画使用 WXSS `@keyframes` 实现，避免影响之前完成的快速跳转逻辑。

## 5. 减少动画

在 `prefers-reduced-motion: reduce` 下：

- 关闭首页进入动画；
- 继续关闭卡片按下缩放；
- 不改变页面内容和功能。

## 6. 修改范围

- `pages/workbench/workbench.wxml`
- `pages/workbench/workbench.wxss`
- `scripts/validate.js`
- `config.js`
- `cloudfunctions/api/package.json`
- `cloudfunctions/api/package-lock.json`
- `cloudfunctions/api/index.js`

不修改：

- `pages/workbench/workbench.js`
- 制作记录数据和预览逻辑；
- 制作页和人脸模型加载逻辑；
- 云函数业务逻辑。

## 7. 验收标准

1. 开始新创作和导出入口箭头字号、位置一致；
2. 制作记录显示“查看全部 ›”，文字功能不丢失；
3. 最新记录预览的小箭头仍然存在；
4. 首页主体进入时只执行一次 `180ms` 淡入上移动画；
5. 动画没有延迟且不阻挡点击；
6. 减少动画模式下不执行进入动画和按下缩放；
7. 快速跳转逻辑没有退回等待遮罩；
8. 静态检查、图片检查、手势检查和兼容性检查全部通过；
9. 版本从 `0.9.0` 升级到 `0.10.0`；
10. 生成 `wechat-miniapp-release-v0.10.0.zip` 正式发布包。
