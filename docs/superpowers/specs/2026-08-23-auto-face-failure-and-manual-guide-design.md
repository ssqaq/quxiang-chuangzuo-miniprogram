# 自动贴脸失败原因与手动圈选提示设计

## 目标

让用户在自动识别人脸失败后知道失败原因、下一步怎么处理，并把手动画圈操作说明改成能直接照着做的短提示。

## 方案

### 失败原因

前端继续复用现有错误对象、错误码、HTTP 状态码和请求编号，新增一层面向用户的中文说明：

- 云端未连接：提示检查网络或稍后重试；
- 主图缺失、上传失败或图片过大：提示重新选择或等待上传；
- 请求超时、网络失败、服务端 5xx：提示重试；
- 没识别到清晰人脸：提示使用脸部更清楚、无遮挡、光线更好的照片；
- API Key、接口配置或其他未知错误：提示保留请求编号并联系后台。

失败弹窗展示“原因 + 下一步 + 手动圈选方法”，自动贴脸状态卡片保留简短失败原因；请求编号继续显示，便于排查。

### 手动圈选提示

根据图片是否缩放和是否刚从自动贴脸失败回退，动态显示简短指引：

- 普通状态：单指拖动圈住整张脸，不要只点一下；双指可放大；
- 已缩放：双指拖动找位置，单指拖动圈住整张脸；
- 自动失败后：明确告诉用户自动识别没成功，需要手动圈住完整人脸。

不改变红圈坐标计算、双指缩放、图片上传和生图流程。

## 验收

1. 每类常见自动贴脸失败都能显示可理解的原因和下一步；
2. 未知错误仍保留原始错误摘要和请求编号；
3. 手动圈选提示能随缩放状态变化；
4. 自动贴脸失败后，用户能直接看到“请圈住整张脸”的指引；
5. 现有静态检查、自动贴脸回退 smoke 和页面相关测试通过；
6. 升一个 patch 版本，生成正式发布包和预览码。
