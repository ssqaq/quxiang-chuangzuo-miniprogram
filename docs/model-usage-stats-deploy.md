# 模型用量统计部署说明

## 需要创建的云开发集合

在 CloudBase 数据库中新建空集合：

```text
model_usage_events
```

权限建议设置为只允许云函数读写，不开放客户端直接读写。

## 部署顺序

1. 上传并部署 `cloudfunctions/api` 云函数。
2. 确认云函数环境变量里的 `ADMIN_OPENIDS` 包含管理员微信 OpenID。
3. 导入并编译小程序包。
4. 用管理员账号进入“管理员配置”页面。
5. 点击“刷新统计”，查看今天、最近7天、最近30天的三类模型用量。

## 统计口径

- 生图：统计真正调用生图上游接口的次数。
- 人脸识别：统计真正调用人脸识别上游接口的次数。
- 视频：只统计创建视频任务，不统计查询任务状态的轮询。
- 失败请求也会记录在总次数里，并单独显示失败数。
- 日期按北京时间（`Asia/Shanghai`）计算。

统计功能上线前的历史调用没有完整记录，不会虚假补录。
