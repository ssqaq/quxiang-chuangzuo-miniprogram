# 创作页顶部卡片方案 B 设计说明

日期：2026-08-23

## 目标

重新排列创作页顶部卡片，解决副标题被右侧按钮挤压换行、状态和按钮堆在右侧导致视觉失衡的问题。

## 最终布局

卡片改为纵向三层：

1. 第一层：左侧显示“圈像创作”，右侧显示“云端已连接”或“本地预览”。
2. 第二层：单独显示“区域锁定 · 人像参考 · AI 提示词”，尽量保持单行。
3. 第三层：显示全宽“返回工作台”按钮。

## 视觉规则

- 卡片保留现有浅蓝到白色背景和圆角。
- 标题继续作为最醒目的内容。
- 连接状态缩小内边距，降低视觉重量。
- 副标题不再和按钮争抢横向空间。
- 返回按钮宽度为卡片内容区的 100%，高度略低于主要操作按钮，保持次级导航样式。
- 标题行、说明行、按钮行之间使用一致的垂直间距。

## 响应式要求

- 375px 和 414px 宽度下，副标题不出现单字掉到下一行。
- 更窄屏幕允许副标题整体换行，但不能被状态标签或按钮挤压。
- 状态标签文字不可压缩或断行。
- 返回按钮文字始终水平、垂直居中。

## 行为和数据

- 不修改 `cloudReady` 状态判断。
- 不修改 `backToWorkbench` 点击行为。
- 只调整 WXML 结构和 WXSS 排版。
- 保留“云端已连接”和“本地预览”两种状态显示。

## 验证

- 静态检查必须通过。
- 新增校验，确认顶部卡片使用纵向布局、状态位于标题右侧、返回按钮为全宽。
- 检查 375px 和 414px 对应样式。
- 修改完成后按补丁版本升级并生成正式发布包。
