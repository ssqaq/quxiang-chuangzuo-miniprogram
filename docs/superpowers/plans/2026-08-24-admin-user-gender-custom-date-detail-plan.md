# 管理页用户性别筛选、自定义日期与用户详情实施计划

## 1. 扩展云函数筛选

- 标准化性别、日期范围和自定义起止日期。
- 在完整用户资料上组合搜索、日期和性别条件。
- 返回筛选后的统计、分页和筛选状态。
- 让 Excel 导出使用同一套组合筛选。

## 2. 扩展小程序请求

- 用户统计和导出请求增加性别、开始日期、结束日期。
- 页面保存当前性别和自定义日期。
- 切换条件后从第一页重新加载，加载更多沿用当前条件。

## 3. 增加页面交互

- 增加全部、男性、女性筛选按钮。
- 日期选项增加“自定义”，展开两个日期选择器。
- 用户卡片增加点击操作，打开底部详情卡片。
- 详情显示匿名资料和时间，不显示 OpenID。

## 4. 验证与发布

- 增加组合筛选、自定义日期、详情隐私和筛选导出专项测试。
- 保留并验证并发的成本显示修改。
- 完整测试通过后升级版本、生成正式 ZIP 并同步 GitHub。
