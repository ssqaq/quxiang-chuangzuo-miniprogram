# 保护选项与页面导航精简设计

## 目标

- 删除重复且占空间的“开始制作 / 制作记录”底部导航。
- 第 5 步继续保留“查看制作记录”，制作记录页增加“返回制作”。
- 把原来的“额外锁定要求（可选）”替换为“选择不需要修改的内容”。
- 复用桌面端 13 个固定保护选项，并支持填写额外保护内容。

## 保护选项界面

- 默认折叠，仅显示标题、说明和已选数量。
- 点击标题区域展开或收起。
- 展开后使用可换行的多选按钮展示 13 个固定项目。
- 默认 13 项全部选中；蓝色表示保持原图，灰色表示允许修改。
- 自定义保护内容使用 180rpx 高的多行文字框，每行填写一项。

## 数据与提示词

- 固定选择保存到 `project.lockedElements`。
- 自定义多行内容按换行或分号拆分，保存到 `project.customLockedElements`。
- 两类保护内容继续进入后台提示词和负面约束，不需要显示提示词草稿。

## 页面导航

- 删除 `tabBar` 配置和 `custom-tab-bar` 组件。
- 第 5 步通过 `navigateTo` 打开制作记录。
- 制作记录页通过“返回制作”优先返回上一页；没有上一页时重新打开制作页。
- 页面底部恢复普通安全区域留白，不再为底栏保留大块空间。

## 验收条件

1. 页面底部不再出现“开始制作 / 制作记录”。
2. 第 5 步“查看制作记录”可正常打开记录页。
3. 记录页顶部“返回制作”可正常返回。
4. 13 个选项默认全选，可以单独取消和重新选择。
5. 自定义文字框明显加高，内容刷新后仍保留。
6. 固定和自定义保护内容都进入后台提示词。
