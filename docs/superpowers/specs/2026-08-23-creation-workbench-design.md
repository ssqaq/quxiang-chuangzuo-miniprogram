# 圈像创作工作台入口设计

## 1. 目标

当前小程序启动后经过 splash 页面直接进入制作页。制作页包含主图、红圈、参考素材、提示词和生成五个步骤，功能完整但信息密度高，不适合作为第一次进入时的首页。

本次新增一个“创作工作台”页面，放在制作页之前，承担三个职责：

1. 让用户先选择这次要做的事情；
2. 让用户能继续上次未完成的草稿；
3. 让用户快速进入制作记录。

本次不重写制作流程，不把四种入口拆成四套页面，也不改变云函数、图片处理、人脸识别和提示词生成逻辑。

## 2. 用户流程

### 2.1 启动流程

```text
splash
  ↓ 1.2 秒后
创作工作台
  ├─ 局部换脸 → 制作页
  ├─ 换穿搭   → 制作页
  ├─ 调姿势   → 制作页
  ├─ 新建创作 → 制作页
  ├─ 继续上次编辑 → 制作页并恢复草稿
  └─ 查看制作记录 → 记录页
```

`pages/splash/splash.js` 将跳转目标从 `/pages/index/index` 改为 `/pages/workbench/workbench`。

### 2.2 新建和继续编辑

- “继续上次编辑”只在本地存在有效草稿时显示。
- 有效草稿定义为：存在主图、红圈、参考素材、提示词或生成结果中的任意一项。
- “新建创作”在没有草稿时直接进入制作页。
- “新建创作”在有草稿时弹出确认框，明确提示当前草稿会被清除；用户取消时留在工作台。
- “继续上次编辑”不清除任何本地缓存。

## 3. 页面结构

新增文件：

```text
pages/workbench/workbench.js
pages/workbench/workbench.json
pages/workbench/workbench.wxml
pages/workbench/workbench.wxss
```

页面从上到下分为五块：

### 3.1 顶部品牌区

- 标题：`圈像创作`
- 副标题：`圈定想改的，创作想要的。`
- 右侧显示 `云端已连接` 或 `本地预览`
- 使用现有品牌图标或轻量 CSS 圆环装饰，不引入新的大图资源

### 3.2 主任务区

标题：`今天，想创作什么？`

副标题：`先选入口，后面按需补素材。`

工作台只保留一个主入口卡：

| 入口 | 说明 | 强调色 | 传入模式 |
|---|---|---|---|
| 开始新创作 | 不预设重点，自定义制作流程 | `#1F6FEB` | `custom` |

换脸、换穿搭和调姿势不再在工作台单独展示，统一在制作页的五步流程中完成。制作页仍然以原有五步流程为准，不能跳过主图、红圈等必要步骤。

### 3.3 草稿恢复区

有有效草稿时显示：

- 草稿名称，默认使用项目名；
- 当前主图缩略图；
- 已完成进度，例如 `主图 · 红圈 · 参考素材`;
- `继续编辑`按钮。

没有有效草稿时显示：

- `还没有未完成项目`
- `从上传一张主图开始`

### 3.4 最近记录区

读取现有 `storage.loadRecords()`，最多显示两条最近结果：

- 结果缩略图；
- 项目名称；
- 生成时间；
- `查看全部记录`按钮。

记录为空时显示空状态，不显示虚假的占位图片。

### 3.5 底部信息

- 显示版本号；
- 显示当前云端或本地状态；
- 使用品牌话术：`局部创作，整体可控`。

## 4. 视觉设计

沿用现有全局样式，不改变制作页已有组件的颜色和间距基线。

| 用途 | 颜色 |
|---|---|
| 页面背景 | `#F5F7FB` |
| 卡片背景 | `#FFFFFF` |
| 主文字 | `#182132` |
| 次文字 | `#697386` |
| 主按钮 | `#1F6FEB` |
| 换脸入口 | `#FF4D55` |
| 穿搭入口 | `#7357D8` |
| 姿势入口 | `#16A085` |
| 边框 | `#E7EBF2` |

设计约束：

- 卡片圆角保持 `24rpx`，任务卡可使用 `20rpx`；
- 页面左右边距沿用 `28rpx`；
- 不使用大面积渐变、复杂插画或高频动画；
- 顶部只保留一个“红圈 + 蓝点”的视觉记忆点，呼应核心圈选能力；
- 点击反馈使用轻微透明度和位移，不增加长时间动画；
- 尊重减少动效设置。

## 5. 数据和跳转

### 5.1 工作台数据来源

工作台只读取现有数据：

- `config.appVersion`
- `cloud.isCloudReady()`
- `storage.loadProject()`
- `storage.loadRecords()`

不新增持久化字段，不改变现有 `PROJECT_KEY` 和 `RECORDS_KEY`。

### 5.2 进入制作页

任务卡使用 query 参数传递入口模式：

```text
/pages/index/index?mode=custom&new=1
```

制作页在 `onLoad(options)` 中读取 `mode`：

- 保存为页面内的临时 `entryMode`；
- 显示一条与入口匹配的引导提示；
- 不改变原有上传、圈选、参考素材、分析和生成逻辑。

继续编辑使用：

```text
/pages/index/index?resume=1
```

制作页继续使用已有的 `storage.loadProject()` 恢复草稿。

### 5.3 新建草稿

工作台确认新建后调用现有 `storage.clearProject()`，再进入制作页。

清除只针对当前项目草稿，不删除：

- 人脸参考文件；
- 穿搭参考文件；
- 制作记录；
- 云端结果。

## 6. 异常和边界

- 本地缓存读取失败：工作台显示空状态，允许继续新建，不阻塞进入制作页。
- 云端未连接：显示 `本地预览`，记录区回退到本地记录。
- 草稿图片路径失效：仍显示草稿文字和进度，缩略图隐藏或显示空占位，不阻塞继续编辑。
- 记录图片路径失效：隐藏缩略图，保留项目名和时间。
- 重复快速点击入口：进入前设置页面级锁，避免重复压入多个制作页。
- 用户取消新建确认：不清缓存，不跳转。

## 8. 测试验收

### 页面和跳转

1. 启动小程序后，splash 能进入工作台，不再直接进入制作页。
2. 四个任务入口都能进入制作页。
3. 任务入口对应的引导提示正确显示。
4. 工作台返回制作页时不会重复创建页面。
5. 查看全部记录能进入现有记录页。

### 草稿

1. 无草稿时显示空状态。
2. 有草稿时显示缩略图、项目名和进度。
3. 继续编辑能恢复主图、红圈、参考图和提示词。
4. 新建创作会先确认，取消不会删除草稿。
5. 确认新建后只清除项目草稿，不清除记录。

### 兼容性

1. 云端连接和本地预览两种状态都能正确显示。
2. 记录为空、记录图片失效、草稿图片失效时页面不崩溃。
3. 小屏手机上任务卡仍保持两列且文字不溢出。
4. 减少动效设置下页面不出现持续动画。
