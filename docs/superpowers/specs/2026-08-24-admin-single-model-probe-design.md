# 管理后台单模型探测设计

## 目标

在保留“探测四套模型”功能的同时，让管理员可以只重新探测人脸识别、图片分析、生图或视频中的某一项。

## 交互

- 四模型探测结果的每一行右侧增加“单独探测”按钮。
- 点击后只请求该行对应的模型类型。
- 探测期间按钮显示“探测中”，避免重复点击。
- 单项结果返回后，只替换该模型的结果，其他三项已有结果保持不变。
- 顶部“探测四套模型”按钮继续保留。

## 接口

- 继续使用 `probeModels` action。
- 新增可选参数 `modelType`，只允许 `face`、`analysis`、`image`、`video`。
- 未传 `modelType` 时保持原逻辑，一次探测四套模型。
- 传入非法类型时返回 `invalid-model-type`，不发起上游请求。

## 安全和成本

- 探测继续使用 `GET /models`，不发起生图或视频生成任务。
- 探测不写模型用量统计，不产生模型生成费用。
- API Key 仍只从云函数环境变量读取。

## 验证

- 单项探测只返回一个结果。
- 非法模型类型被拒绝。
- 单项结果合并后不会清除其他模型结果。
- 四模型探测原功能保持兼容。
- 完整静态检查、正式打包、云函数部署和真机预览均需通过。
