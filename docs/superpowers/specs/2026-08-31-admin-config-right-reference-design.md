# 功能配置页右图还原设计

## 目标

以用户最后提供的四张右侧 `390 x 844` 参考图为唯一视觉标准，重做 `pages/admin-config` 的三种折叠状态，并同步还原 `pages/admin-provider`。保留正式 `0.57.82` 的供应商、主备模型、保存和真实统计逻辑，不保留左侧旧版的视觉结构。

## 页面结构

1. 使用自定义导航，避免微信原生标题栏与页面标题重复。
2. 导航栏只显示 `功能配置` 和 `供应商管理`，删除右图没有的返回箭头，并为状态栏、胶囊和刘海保留安全区。
3. `开始新创作` 与 `开始新创作-腾讯版` 使用单行四段选择器，只显示功能名称，不显示旧版图标和逐项状态文字。
4. 腾讯版异常状态放在分组标题右侧，以橙色标签显示。
5. `共享视频模型` 使用左侧标题与说明、右侧紧凑按钮的独立布局。
6. `配置总览` 同时承载主模型状态与 `展开/收起` 控制。主模型详情默认不显示，展开后在总览和故障切换之间显示独立白色实线卡。
7. `故障切换` 默认折叠备用模型详情。`高级参数` 作为同一卡片底部的折叠行，不再单独占一张卡。
8. 保存按钮保持页面底部全宽蓝色主操作。
9. 供应商页关闭原生导航并删除返回箭头；内容放进白色外卡，编辑态隐藏不可变供应商 ID，左栏首屏显示八条并隐藏滚动条。

## 视觉规则

- 以 `390 x 844` 为基准，使用 `rpx` 自适应其他手机宽度。
- 字体优先 `PingFang SC`，不再用全页 `Microsoft YaHei` 和 `font-weight: 600` 强制覆盖。
- 页面底色、蓝色主按钮、浅蓝选择器、绿色正常状态和橙色待配置状态跟随右图。
- 标题、说明、统计数字形成清晰三级字号；紧凑控件必须保持单行且不裁切。
- 卡片圆角不超过右图视觉尺寸，卡片之间使用稳定的垂直间距。
- 所有文字在 `320px` 到 `430px` 宽度内不得重叠或横向溢出。

## 数据与交互

- `配置总览` 的 `已配置功能` 与 `备用模型` 数字继续读取真实云端配置，禁止为了匹配参考图硬编码成 `4 / 4` 或 `3 个已启用`。
- 切换功能时，主模型、备用模型和高级参数都恢复折叠状态。
- 高级参数展开后使用两行两列布局，并显示“保留原 Key”“保存前校验”和作用范围说明。
- 保存、供应商选择、模型选择、备用开关、超时和重试逻辑保持原行为。
- 保存按钮必须防重复点击；主模型已写入但备用写入失败时重新读取云端，明确提示部分保存，不能假装整体成功或伪回滚。
- 待配置状态不阻止用户展开并补齐配置。

## 验收

1. WXML/WXSS 静态检查覆盖自定义导航、分组结构、总览内主模型和统一故障卡。
2. 运行时检查覆盖三个折叠状态默认关闭、切换功能后仍关闭、保存数据不变。
3. 完整运行 `node scripts/validate.js`。
4. 正式打包后导入微信开发者工具，使用 `390 x 844` 设备编译并与右图截图对照。
