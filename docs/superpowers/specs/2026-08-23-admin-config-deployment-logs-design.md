# 管理员模型配置页与部署检查日志设计

## 目标

为微信小程序增加一个管理员配置页，支持在线调整生图模型和视频模型的非敏感参数；同时增加线上部署检查和检查日志，方便确认云函数是否已经部署到预期版本。

API Key、AppSecret、管理员 OpenID 白名单等敏感内容继续只放云函数环境变量，不进入小程序前端、云数据库、发布包或普通日志。

## 方案选择

### 方案 A：只读环境变量

配置页只展示环境变量，修改仍然需要重新部署云函数。

缺点：不能满足在线调整模型参数的需求，操作成本高。

### 方案 B：环境变量保密 + 云数据库动态配置

环境变量保存密钥和管理员白名单，云数据库保存可动态修改的模型参数。云函数读取环境变量作为默认值，再叠加数据库中的非敏感覆盖配置。

优点：不暴露密钥，修改后立即生效，不需要每次重新部署。采用此方案。

### 方案 C：独立后台系统

另建管理后台和鉴权服务。

缺点：当前小程序规模不需要，开发和部署成本明显增加。

## 页面与访问控制

新增页面 `/pages/admin/admin`。

工作台只在云函数确认当前 OpenID 属于管理员时显示“管理员配置”入口。即使普通用户手动访问页面地址，页面初始化和所有写操作仍由云函数再次校验管理员身份。

管理员白名单来自云函数环境变量：

```text
ADMIN_OPENIDS=openid1,openid2
```

支持逗号和换行分隔。前端只接收 `isAdmin` 布尔值，不接收白名单内容。

## 可配置内容

### 生图模型

- Provider
- Base URL
- Endpoint
- Model
- 图片模式：`generations` 或 `edits`
- 图片尺寸
- 超时时间
- 最大重试次数
- 是否开启生图重试

### 视频模型

- Provider
- Base URL
- 创建任务 Endpoint
- 查询任务 Endpoint
- Model
- 创建路径
- 查询路径
- 分辨率
- 宽高比
- 超时时间

API Key 不在页面展示或编辑。云函数只返回“已配置/未配置”状态。

## 云函数接口

新增动作：

- `getAdminStatus`：返回当前用户是否为管理员。
- `getAdminConfig`：返回脱敏后的环境默认值、数据库覆盖值和最终生效配置。
- `saveAdminConfig`：校验并保存非敏感配置。
- `checkDeployment`：返回当前云函数构建标记、版本、配置状态，并写入检查日志。
- `listDeploymentLogs`：读取最近的部署检查日志。

配置文档保存到 `admin_runtime_config/global`。文档包含：

- `image`
- `video`
- `version`
- `updatedAt`
- `updatedBy`

云函数读取动态配置时使用短时缓存，降低每次生图和视频请求对数据库的压力。保存配置后立即清理缓存。

## 部署检查日志

日志文档保存到 `admin_deployment_logs`，每次管理员主动检查写入一条，最多展示最近 20 条。

日志只包含：

- 检查时间
- 请求编号
- 小程序版本
- 云函数构建标记
- 云函数版本
- 环境 ID
- 生图配置是否完整
- 视频配置是否完整
- API Key 是否存在
- 动态配置更新时间
- 检查结果和错误代码

不记录 API Key、完整请求体、图片 Base64、视频提示词或用户素材。

## 配置生效链路

1. 云函数启动时读取环境变量默认值。
2. 管理员打开配置页，读取环境默认值和数据库覆盖值。
3. 管理员保存配置，云函数校验字段并写入数据库。
4. 生图和视频请求读取最终生效配置。
5. API Key 仍从环境变量读取。
6. 配置保存后清理短时缓存，新请求立即使用新配置。

## 校验与错误处理

- 只允许白名单字段进入数据库。
- URL 必须使用 `http` 或 `https`。
- 超时时间、重试次数、分辨率等数值限制在安全范围内。
- 生图模式只允许 `generations` 和 `edits`。
- 空字符串表示清除可选覆盖值，但不能清除必需字段的环境默认值。
- 非管理员统一返回 `ADMIN_FORBIDDEN`。
- 配置非法统一返回明确字段错误，不保存部分结果。
- 数据库不可用时，生图和视频继续使用环境变量默认值；管理员页面显示配置读取失败。

## 测试范围

新增 smoke 覆盖：

- 管理员 OpenID 解析和鉴权。
- 非管理员读取、保存、部署检查均被拒绝。
- 管理员能读取脱敏配置。
- 配置字段校验和白名单过滤。
- 保存配置后最终生效配置正确。
- API Key 不落库、不进入日志和发布包。
- 部署检查返回构建标记并写入日志。
- 最近部署日志读取和数量限制。
