# 管理员页模型名称显示规则

## 目标

管理员页所有模型名称统一使用小写显示；没有模型时统一显示“未配置”。

## 设计

- 在管理员页增加一个仅用于显示的模型名称格式化函数。
- 函数会去掉首尾空格，将真实模型名称转成小写。
- 空值以及现有的占位文案（如“未填写”“未读取”“未知模型”“暂无调用”）统一显示为“未配置”。
- 配置编辑框、保存请求、云函数返回值和复制错误日志继续保留原始值，不做强制小写或替换。
- 当前配置、模型用量、失败统计、模型探针和探针历史都使用统一后的显示值。

## 验证

- 检查管理员页 WXML/WXSS 编译。
- 运行项目现有校验和管理员页专项 smoke 测试。
- 升级项目版本并生成正式发布包。
