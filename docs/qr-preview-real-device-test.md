## 测试前清理

1. 微信开发者工具执行“清缓存并重新编译”。
2. 确认工作台底部版本号不是旧版本。
3. 真机删除旧版预览后重新扫码进入。
4. 不使用旧的预览截图判断新包结果。

## 自动检查

```text
node scripts/image-preview-screenshot-smoke.js
node scripts/qr-real-device-smoke.js
```

自动检查只能证明源码入口、尺寸计算和资源存在；“长按识别”和“另一台手机扫码”必须在真实手机上手工完成。
