# 第 4 步说明迁移与提示词草稿精简设计

## 目标

- 把桌面端源码中的“场景、姿态、面部朝向、光影/妆容与画质”四段完整填写说明原样迁移到微信小程序。
- 删除用户不需要的提示词草稿显示功能，包括生成/刷新按钮、复制按钮、草稿编辑框和负面约束显示。
- 保留后台提示词与负面约束生成逻辑，确保第 5 步生图、归档和网感姿势追加逻辑不受影响。

## 界面

- 四个说明作为对应 `textarea` 的占位提示。
- 四个输入框统一加高，长说明在手机上自然换行。
- 第 4 步底部只保留“去生成”，不再展示提示词草稿卡片。
- 第 5 步不再显示“还没有提示词”的中间状态。

## 数据流程

1. 用户手动填写四段描述，或使用“AI 分析主图”自动填充。
2. 用户点击“去生成”时，小程序在后台根据最新描述生成提示词和负面约束。
3. 用户点击“提交生图并归档”时再次刷新提示词，避免旧缓存导致描述不同步。
4. “参考网感分析”选中的姿势仍只在提交时追加，不覆盖四段描述。

## 验收条件

1. 四段占位说明与桌面端源码完全一致。
2. 页面不再出现“生成 / 刷新提示词”“提示词草稿”“复制”和“负面约束”。
3. 页面 JS 不再保留草稿编辑和复制事件。
4. 从第 4 步进入第 5 步后可以直接提交生图。
5. 静态检查、兼容测试、开发者工具编译和真机预览通过。
