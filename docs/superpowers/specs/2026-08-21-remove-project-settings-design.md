# 删除项目设置卡片与单行输入框兼容修复

## 目标

- 首页不再显示“项目设置”卡片、项目名称输入框和“清空”按钮；
- “额外锁定要求”输入框在微信模拟器和真机上完整显示；
- 保留内部 `projectName` 默认值，兼容现有云函数参数和历史记录结构。

## 修改范围

- 删除首页项目设置 WXML；
- 删除仅由该卡片使用的 `onProjectNameInput` 和 `clearProject` 页面方法；
- 把普通单行 `.input` 的高度、内边距和行高统一设置为兼容值；
- 更新静态回归检查，防止项目设置重新出现或单行输入框再次被压扁；
- 不修改云函数业务、数据库结构和历史记录。

## 验证

- 静态检查确认项目设置卡片和事件绑定已经移除；
- 静态检查确认 `.input` 有明确高度和文字居中规则；
- 执行兼容、图片和部署检查；
- 在微信开发者工具中重新加载并检查首页及提示词步骤。
