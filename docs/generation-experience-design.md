# 生图体验优化设计

## 目标

本轮只改首页生图体验和手机适配，不改变现有制作记录数据结构及主流程。

## 功能设计

### 1. 分阶段进度

首页生图等待卡按实际流程显示四个阶段：

1. 准备素材：整理主图、红圈和参考图。
2. 上传素材：把还没有上传到云端的图片上传完成。
3. AI生成：提交生图请求并等待服务端返回。
4. 保存记录：生成成功后保存本地和云端记录。

等待卡显示当前阶段、阶段说明、预计等待时间、已等待秒数和防重复点击提示。

### 2. 自动重试

只对网络失败、服务端明确标记为可重试、以及请求超时的情况重试，最多自动重试 2 次，每次间隔 2 秒。素材准备和上传阶段不重复执行已经完成的步骤。

每次生成使用唯一请求标识，并把请求标识传给云函数，避免服务端已经成功但客户端没有收到响应时重复创建记录。

### 3. 超时提示

单次生图等待超过 120 秒后，停止当前等待状态并弹窗提示。弹窗提供“重新生成”操作，重新生成沿用当前项目素材，不要求用户重新选择照片。

### 4. 375px / 414px 适配

在现有响应式规则上补充：

- 375px：缩小页面左右边距、标题和等待卡内间距，关键按钮保持可点击高度。
- 414px：增加等待卡内部留白，避免内容挤在一起。
- 阶段文字、重试文字和超时按钮允许自然换行，但不出现横向溢出。

## 错误处理

- 自动重试期间保持等待卡，不弹出重复错误弹窗。
- 达到重试次数后显示明确失败原因和请求编号。
- 页面离开时清理计时器和超时任务。
- 生成成功只保存一条记录。

## 验证

- JavaScript、JSON和微信小程序兼容检查。
- 重试次数、超时分支、唯一请求标识专项测试。
- ZIP完整性和包内关键文案检查。
- 375px、414px样式规则静态检查。
