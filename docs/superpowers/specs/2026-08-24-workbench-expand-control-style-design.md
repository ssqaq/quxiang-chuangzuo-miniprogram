# 工作台展开控件样式统一设计

## 目标

只统一工作台“服务记录”卡片右侧的“展开/收起”控件，让它与“联系作者”卡片右侧控件保持一致；不改变服务记录右侧的统计数字、卡片结构或展开逻辑。

## 现状

- “服务记录”右侧控件使用 `.diagnostic-toggle-indicator`，字号、颜色、箭头尺寸与“联系作者”不同。
- “联系作者”右侧控件使用 `.contact-author-toggle` 和 `.contact-author-toggle-arrow`，视觉规格已经符合目标。
- 两个控件的文字都是“展开/收起”，箭头都随状态变化，因此可以抽出一套共用规格。

## 方案

采用共用样式方案：

1. 在两个展开控件上增加同一个语义样式类。
2. 将以下规格统一到共用样式：
   - 文字字号：`21rpx`
   - 文字颜色：`#2f70d4`
   - 行高：`32rpx`
   - 箭头左间距：`6rpx`
   - 箭头字号：`30rpx`
   - 箭头字重：`700`
   - 箭头行高：`28rpx`
3. 服务记录现有箭头旋转逻辑继续保留，展开状态仍由 `diagnosticExpanded` 控制。
4. 联系作者现有交互和二维码内容不改。

## 影响范围

- `pages/workbench/workbench.wxml`
- `pages/workbench/workbench.wxss`

不修改 `pages/workbench/workbench.js`，不修改统计数字，也不改变任何数据或业务行为。

## 验收标准

- 收起状态下，两个卡片右侧“展开⌄”的文字大小、颜色、箭头大小和上下对齐一致。
- 展开状态下，两个卡片右侧“收起⌃”的规格一致。
- 点击服务记录仍能展开/收起日志。
- 点击联系作者仍能展开/收起二维码。
- 窄屏下右侧控件不与标题或统计数字重叠。
- 静态校验、正式打包和仓库同步通过。
