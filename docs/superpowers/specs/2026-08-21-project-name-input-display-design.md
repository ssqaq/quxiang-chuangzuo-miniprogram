# 项目名称输入框显示修复设计

## 目标

恢复首页“项目设置”卡片内现有的“项目名称”输入框，使其在微信开发者工具模拟器和真机上完整显示输入区域、已有文字和占位文字。

## 修改范围

- 只给项目名称输入框增加独立样式类；
- 明确输入框高度、最小高度、水平内边距和行高；
- 不新增设置项；
- 不修改项目数据结构、存储逻辑、云函数或其他输入框。

## 兼容方案

采用独立类而不是修改全局 `.input`，避免影响“额外锁定要求”等其他输入框。固定高度使用 `rpx`，继续适配不同尺寸的小程序设备。

## 验证

- 静态检查确认 WXML 已引用独立类；
- 静态检查确认样式包含明确高度和行高；
- 执行现有兼容测试、部署检查和发布包完整性检查。
