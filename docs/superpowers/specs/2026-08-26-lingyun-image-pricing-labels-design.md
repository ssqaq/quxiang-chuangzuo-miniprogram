# 图片与视频价格及清晰度显示设计

## 目标

把图片和视频的实际成本记录为人民币单价，并在管理员页面对应的清晰度选择框里直接显示价格。

## 价格

| 清晰度 | 价格 |
|---|---:|
| 1K | ¥0.06/张 |
| 2K | ¥0.10/张 |
| 4K | ¥0.15/张 |

视频当前默认价格：

| 清晰度 | 价格 |
|---|---:|
| 480p | ¥0.20/秒 |
| 720p | ¥0.30/秒 |
| 1080p | ¥1.80/秒 |

## 方案

1. 将图片和视频默认价格集中放在云函数入口
   `cloudfunctions/api/index.js`，只由云端维护默认值。CloudBase 部署曾出现
   自定义相对模块缺失，因此入口保持单文件可启动。
2. 管理员页面不再重复写默认价格，而是读取云函数返回的当前有效成本。
3. 图片清晰度显示为 `1K（¥0.06/张）`，视频清晰度显示为
   `720p（¥0.3/秒）`。
4. 成本输入框和清晰度下拉框共用当前表单里的同一组价格数据，管理员修改价格后两处立即保持一致。
5. 云端价格尚未返回时显示“价格读取中”，不显示可能过期的本地默认值。
6. 如果线上仍是旧图片默认价 `0.015 / 0.025 / 0.035`，云函数自动迁移为
   `0.06 / 0.10 / 0.15`；管理员自定义价格不覆盖。
7. 不改变图片或视频生成接口、尺寸比例、模型选择、积分扣除和原有计费公式。

## 验证

- 成本统计测试确认图片、视频默认价格及旧图片价格迁移。
- 管理员状态测试确认图片、视频下拉框价格随成本输入立即同步。
- 模拟器确认三档视频清晰度都带每秒价格。
- 运行现有项目校验脚本。
- 按项目规则升级补丁版本并完成正式打包。
