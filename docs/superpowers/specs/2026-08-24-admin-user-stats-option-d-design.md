# 管理页用户统计 D 方案设计

## 目标

把管理员页“用户统计”改成用户选定的“人数 + 圆环型”，让管理员一眼看懂：

1. 这里统计的是已完善资料的用户，不是访问人数。
2. 当前共有多少名用户。
3. 男女用户各有多少人、各占多少。
4. 具体用户是谁，原始 OpenID 不对外显示。

## 页面结构

1. 顶部左侧显示“已完善资料 / 用户统计”。
2. 顶部右侧保留“刷新”和“导出”。
3. 单独一行显示大白话说明，避免和按钮挤在同一行后变成竖排。
4. 主统计区左侧突出总用户数，右侧用性别圆环突出女性占比。
5. 下方用两张卡片分别展示男性、女性人数和比例。
6. 最下方保留用户头像、昵称、性别、更新时间、匿名编号和继续加载。

## 状态处理

- 读取中：显示“正在读取用户统计”。
- 读取失败：显示失败原因，并保留刷新入口。
- 已有旧数据但正在刷新：旧数据继续显示，避免页面突然空白。
- 无用户：显示“还没有已完善资料的用户”。

## 视觉约束

- 不改管理页现有蓝白配色。
- 男性使用浅蓝色，女性使用浅粉色。
- 圆环中心显示女性占比。
- 手机窄屏下说明文字必须正常横排，按钮不能挤压说明。
- 不修改用户统计接口和数据结构。

## 验证标准

- 总用户数、男女人数和比例继续绑定现有 `userStats` 数据。
- 刷新、导出、加载更多、收起功能保持可用。
- 原始 OpenID 仍不显示。
- 新增专项静态测试，完整校验通过。
