# 视频模型配置与用户统计导出设计

## 目标

- 接入凌云中转站的 Grok 异步视频接口。
- API Key 只保存在云函数环境变量中，不进入源码、发布包或 GitHub。
- 管理页“用户”入口增加 Excel 导出，方便保存和转发用户统计。

## 视频配置

- Provider：`lingyun`
- Base URL：`https://api.lingyunapi.xyz`
- 模型 ID：`grok-imagine-video-1.5`
- 创建路径：`/v1/videos/generations`
- 查询路径：`/v1/videos/{taskId}`
- 默认清晰度：`720p`
- 计费：
  - 480p：0.2 元/秒
  - 720p：0.3 元/秒
  - 1080p：1.8 元/秒
- 连接验证只读取模型和服务状态，不主动生成收费视频。

## 用户统计导出

新增管理员接口 `exportAdminUserStats`，仅管理员可调用。

Excel 包含：

1. `统计摘要`
   - 总用户数
   - 男性数量、比例
   - 女性数量、比例
   - 导出时间
2. `用户明细`
   - 匿名用户编号
   - 昵称
   - 性别
   - 首次使用时间
   - 最近修改时间

导出文件不包含 OpenID、头像地址、用户素材地址、API Key 和内部文件路径。

## 前端流程

- 用户统计工具栏增加“导出 Excel”按钮。
- 点击后调用云函数生成文件，下载并通过微信文档查看器打开。
- 生成期间按钮显示“生成中”，失败时展示明确错误。

## 测试

- 普通用户不能导出。
- 管理员可以导出空数据和多用户数据。
- 摘要数量及男女比例正确。
- Excel 不包含 OpenID、头像云文件地址和密钥。
- 视频计费与三个清晰度的单价一致。
- 视频状态检查不产生收费任务。
