# 管理页用户搜索、日期筛选与新增趋势实施计划

## 1. 云函数统计逻辑

- 增加搜索词和日期范围的标准化函数。
- 从完整用户资料中筛选昵称、匿名编号和注册日期。
- 在筛选结果上计算总人数、男女数量、比例和分页。
- 从未筛选的完整资料中计算最近 7 天新增趋势。
- 让导出功能使用与页面相同的筛选条件。

## 2. 小程序请求与页面状态

- 扩展 `services/cloud.js` 的用户统计和导出参数。
- 在管理页保存搜索输入、已应用搜索词和日期范围。
- 搜索、清空、日期切换时从第一页重新加载。
- 加载更多时沿用当前搜索和日期条件。

## 3. D 方案页面

- 在说明下方加入搜索框和操作按钮。
- 加入全部、今天、近 7 天、近 30 天筛选按钮。
- 在男女卡片下方加入最近 7 天新增柱状图。
- 空结果时显示“没有符合条件的用户”。

## 4. 测试与发布

- 新增搜索、日期边界、趋势分组、分页和筛选导出专项测试。
- 运行管理页、用户资料和完整静态检查。
- 升级小程序及云函数版本。
- 生成正式 ZIP，验证完整性后同步 GitHub。
