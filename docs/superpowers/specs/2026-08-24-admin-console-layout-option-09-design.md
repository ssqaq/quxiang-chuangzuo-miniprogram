# 管理员控制台方案 9 排版设计

## 目标

把现有管理员配置页从“所有统计和表单全部展开”改成一眼能看懂的控制台。
管理员进入页面后，第一眼先看到：

1. 线上是否正常；
2. 生图模型；
3. 视频模型；
4. 积分规则；
5. 成本价格。

探针、接口耗时、失败统计、模型用量和部署日志继续保留，但统一放入默认收起的“运行监控”。

## 页面结构

### 1. 顶部标题

- 标题使用“控制台”。
- 显示管理员身份。
- 保留返回工作台入口。

### 2. 深色线上状态台

- 使用深蓝色整块状态台，作为页面唯一的强视觉重点。
- 显示总体状态、当前小程序版本、最近探针耗时和今日失败数。
- “检查线上部署”按钮直接放在状态台内。
- 状态不只用颜色表示，同时显示“运行正常”“需要检查”等文字。

### 3. 四个配置入口

- 生图、视频、积分、成本四个入口并排显示。
- 点击入口，只展开对应的一组配置表单。
- 再次点击当前入口可收起。
- 四个入口最小点击区域不小于 88rpx。

### 4. 当前配置

- 生图模型和视频模型始终显示一行摘要。
- 摘要显示 Provider、Model、尺寸或清晰度、Key 是否已配置。
- 点击摘要可直接打开对应配置。

### 5. 今日概览

- 只保留三个数字：今日调用、今日失败、今日预计成本。
- 详细用量按日、用户、模型和月份统计移入运行监控。

### 6. 配置编辑区

- 每次只展开生图、视频、积分或成本中的一项，避免页面同时出现大量输入框。
- 保留现有全部字段、输入绑定、重试开关和保存逻辑。
- 保存按钮放在展开的编辑区下方。

### 7. 运行监控

- 默认收起。
- 展开后继续显示：
  - 当前线上部署；
  - 自动贴脸探针和接口耗时；
  - 探针历史；
  - 模型用量统计与 Excel 导出；
  - 自动贴脸失败统计；
  - 部署检查日志。
- 原有刷新、导出和检查按钮继续可用。

## 视觉规则

- 页面背景：浅灰蓝。
- 主状态台：深海军蓝。
- 正常状态：绿色文字和浅绿色标签。
- 警告状态：橙色文字和浅橙色标签。
- 配置入口使用蓝、绿、紫、金四种低饱和强调色。
- 不使用 Emoji 作为结构图标，入口使用“图、视、积、¥”字符。
- 所有按钮和入口提供按下反馈，页面底部保留安全区间距。

## 数据与兼容

- 不修改云函数接口和数据库结构。
- 不记录或显示 API Key、图片、提示词和完整用户身份。
- 不改变现有管理员白名单判断。
- 不改变现有保存配置、部署检查、探针、统计和导出数据格式。

## 验证

1. 管理员进入后先看到状态台和四个配置入口。
2. 四个入口能分别打开并收起对应配置。
3. 生图、视频、积分和成本所有字段都能编辑并保存。
4. 运行监控默认收起，展开后旧功能完整可用。
5. 探针耗时、探针历史、失败统计和用量统计都能正常显示。
6. 小屏手机无横向滚动，按钮不被底部安全区遮挡。
7. 静态检查和现有 smoke 测试通过后升级补丁版本并生成正式发布包。
