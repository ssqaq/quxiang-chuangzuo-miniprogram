# 管理员页统计区块顺序调整设计

## 目标

将管理员页“模型用量统计”下方四个可折叠统计区块调整为：

1. 按模型名称分组
2. 按用户统计
3. 按月份统计
4. 最近 30 天每日明细

## 方案

只调整 `pages/admin/admin.wxml` 中四个统计区块的排列位置，保留每个区块原有的：

- `data-usage-section` 标识
- `toggleUsageSection` 点击逻辑
- `usageSections` 展开/收起状态
- 统计数据绑定和空状态文案
- 现有样式类名

不修改统计计算、云函数、导出功能或失败统计模块。

## 验证

- 检查 WXML 四个标题的源码顺序。
- 运行项目现有 `scripts/validate.js`。
- 运行发布包检查并确认生成非空发布包。
