# 媒体解析功能块紧凑化设计

## 目标

收紧媒体解析页输入卡片中“解析高清媒体”和“提取作品文案”两个功能信息块，消除卡片底部多余留白，并提高功能说明的可读性。

## 现状与原因

- 两个功能块是现有 `view.feature-option` 信息展示，不是可点击按钮，不增加交互。
- `.input-card` 当前使用 `padding-bottom: 122rpx`，而功能行后没有需要预留空间的绝对定位内容，因此产生大块空白。
- 功能块标题和副标题字号偏小，在窄屏上不够易读。

## 实现方案

只调整 `pages/watermark-remover/watermark-remover.wxss`：

- 输入卡片恢复为四边 `22rpx` 内边距。
- 功能块 `min-height` 调整为 `84rpx`，四边内边距调整为 `12rpx`。
- 功能块标题调整为 `22rpx / 30rpx`，副标题调整为 `18rpx / 26rpx`。
- 保留两列宽度、图标、勾选标记、文本省略和现有页面逻辑。

不修改 WXML、页面 JS、云函数或接口。

## 验收

1. 375、390、430 宽度下两个功能块等高，标题和副标题不发生重叠或异常截断。
2. 输入卡片底部只保留正常内边距，底部操作区随卡片自然上移且不重叠。
3. 长分享文本使 textarea 增高时，功能块仍保持正常排列。
4. `watermark-m0-smoke.js`、`validate.js` 和 `git diff --check` 全部通过。
