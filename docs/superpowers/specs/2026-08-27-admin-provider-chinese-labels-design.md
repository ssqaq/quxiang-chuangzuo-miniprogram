# 管理员服务商中文统一显示设计

## 目标

管理员页面中已知服务商统一显示中文：

- `xingju` 显示为“星炬”；
- `lingyun` 显示为“凌云”；
- `dashscope` 显示为“阿里云百炼”。

未知或自定义服务商保持原内容，不擅自改名。

## 数据流

1. 云端配置加载到表单时，把已知英文标识转换成中文名称。
2. 管理员输入已知英文标识时，输入框自动显示对应中文名称。
3. 保存配置、测试连接、获取模型前，把中文名称转换回原英文标识。
4. 模型探测、失败统计等管理员可见区域也使用相同中文显示规则。

这样只改变页面显示，不改变云端保存格式和现有接口协议。

## 兼容规则

- 旧配置里的英文标识继续正常加载。
- 已经保存为中文的历史配置也能自动恢复成英文标识发送给后端。
- 自定义服务商不在映射表中时，显示和提交都保持原样。

## 验证

- 视频配置中的 `lingyun` 显示为“凌云”。
- 人脸和图片分析配置中的 `dashscope` 显示为“阿里云百炼”。
- 生图主备继续显示“星炬”和“凌云”。
- 保存、测试连接、获取模型收到的仍是英文标识。
- 管理员页面专项测试和项目总验证通过。
