# 媒体解析页两块提示删除设计

## 目标

按用户截图删除媒体解析页中两处不需要的界面内容：

1. 页面顶部的 `MEDIA PARSER` 标签。
2. 页面底部的解析服务状态卡及紧随其后的免责声明。

## 范围

- 修改 `pages/watermark-remover/watermark-remover.wxml`，删除对应界面节点。
- 修改 `pages/watermark-remover/watermark-remover.wxss`，删除不再使用的样式并收紧标题顶部间距。
- 修改 `scripts/watermark-m0-smoke.js`，增加目标元素不得再次出现的检查。

## 保留内容

- 页面标题、输入框、开始解析按钮、结果展示和返回工作台入口。
- 解析网关健康检查、真实解析请求、错误处理和保存到相册功能。
- 其他页面和云函数业务逻辑。

## 验收标准

1. 页面不再出现 `MEDIA PARSER` 标签。
2. 页面不再出现解析服务状态卡。
3. 页面不再出现“仅处理本人发布或已获授权的内容”免责声明。
4. 页面加载、解析、结果展示及保存功能保持可用。
5. 媒体解析专项测试和项目完整静态检查通过。
