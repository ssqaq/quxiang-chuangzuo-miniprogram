# 管理页用户性别筛选、自定义日期与用户详情设计

## 目标

在现有用户统计 D 方案和搜索、日期筛选、趋势图基础上增加：

1. 按全部、男性、女性筛选已完善资料用户。
2. 自己选择开始日期和结束日期。
3. 点击用户卡片查看完整资料。

三个功能必须和搜索、分页、人数统计、男女比例、导出共同生效，同时继续隐藏原始 OpenID。

## 性别筛选

- 增加“全部、男性、女性”三个选项。
- 性别筛选与昵称或匿名编号搜索、日期筛选同时生效。
- 顶部总人数、男女数量、比例和用户明细都显示当前筛选结果。
- Excel 只导出当前搜索、日期和性别条件下的用户。

## 自定义日期

- 现有“全部、今天、近7天、近30天”后增加“自定义”。
- 选择“自定义”后显示开始日期和结束日期两个日期选择器。
- 默认范围为最近7天，结束日期不能超过今天。
- 如果开始日期晚于结束日期，自动把另一端调整为同一天，避免无结果和报错。
- 自定义日期按 `Asia/Shanghai` 判断，开始和结束日期都包含在结果内。

## 用户详情

- 点击用户明细卡片，从页面底部弹出详情卡片。
- 详情显示头像、昵称、性别、匿名编号、首次完善资料时间、最近修改时间。
- 点击关闭按钮或灰色背景可关闭。
- 详情直接使用已经加载的匿名资料，不额外返回或展示 OpenID。

## 状态与空结果

- 切换性别或日期后自动从第一页重新读取。
- 搜索、日期、性别可以同时使用。
- 无结果时继续显示“没有符合条件的用户”。
- 接口失败时保留原数据并显示原有错误提示。

## 验证标准

- 全部、男性、女性筛选数量正确。
- 自定义日期边界包含开始和结束当天。
- 搜索、日期、性别组合筛选正确。
- 加载更多继续沿用所有筛选条件。
- Excel 摘要写明日期和性别条件，并只包含筛选后的用户。
- 用户详情显示完整匿名资料，不显示 OpenID。
- 并发的成本四位小数截断修改保持不变。
- 专项测试和完整静态检查通过。
