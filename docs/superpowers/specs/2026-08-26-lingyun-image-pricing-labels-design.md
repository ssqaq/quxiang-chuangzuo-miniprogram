# 凌云生图价格与清晰度显示设计

## 目标

把凌云图片生图的实际成本记录为人民币单价，并在管理员页面的生图清晰度选择框里直接显示对应价格。

## 价格

| 清晰度 | 价格 |
|---|---:|
| 1K | ¥0.06/张 |
| 2K | ¥0.10/张 |
| 4K | ¥0.15/张 |

## 方案

1. 云函数成本配置的默认值改为上面三档价格，继续保留已有运行时配置覆盖能力。
2. 管理员页面根据当前成本表动态生成清晰度选项，显示为 `1K（¥0.06/张）` 这种格式。
3. 成本输入框和清晰度下拉框共用同一组价格数据，管理员修改价格后两处保持一致。
4. 不改变图片生成接口、图片尺寸比例、模型选择、积分扣除或视频成本。

## 验证

- 静态检查确认三档默认值和动态标签存在。
- 运行现有项目校验脚本。
- 按项目规则升级补丁版本并完成正式打包。
