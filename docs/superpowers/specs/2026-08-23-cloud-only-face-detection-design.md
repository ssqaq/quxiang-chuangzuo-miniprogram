# 纯云端自动人脸识别设计

任务 ID：`T-20260822-143938-01`

## 已确认事实

- 真机与模拟器均无法稳定运行当前 MediaPipe/WASM 本地识别。
- CloudBase 环境 `cloud1-d4g05zdxc94d17112` 和 `api` 云函数真实存在。
- 小程序与云函数源码已有 `detectFaceCircle` 调用和坐标转换。
- 线上云函数曾因相对模块 `./lib/retry` 加载失败而在入口阶段崩溃。
- 用户已明确批准：云端真实可用后删除本地识别。

## 方案选择

采用纯云端方案，不保留正式流程里的本地识别和 WASM 探针：

```text
用户选择主图
→ 上传主图到云存储
→ 调用 api/detectFaceCircle
→ 云端返回人脸坐标并自动画圈
→ 云端失败时进入手动圈选
```

不采用以下方案：

- 本地优先、云端兜底：已被真实真机日志证明不稳定，会继续拖慢首次操作。
- 用开关保留本地识别：增加维护和误启风险，没有当前交付价值。

## 实施顺序

1. 把云函数入口依赖的本地辅助函数内联，消除云端相对模块加载失败。
2. 部署云函数并做安全空参数调用：
   - 返回 `missing-main-image`：证明路由、运行包和 `AI_API_KEY` 均可用。
   - 返回 `missing-api-key`：停止删除本地代码，先补云端配置。
3. 云端验证通过后：
   - `autoFaceCircle()` 只调用云端；
   - 删除应用启动时的本地运行时订阅；
   - 删除 `utils/local-face.js` 和 `utils/face-runtime/`；
   - 删除本地模型/WASM 配置和对应兼容测试；
   - 保留云端诊断日志和手动圈选保底。
4. 运行完整验证，升级修复版本，部署云函数，正式打包并生成新预览码。

## 验收标准

- 云函数安全探针返回 `missing-main-image`。
- 自动贴脸测试覆盖“云端成功”和“云端失败转手动”。
- 小程序源码和发布包不再引用 `local-face`、`WXWebAssembly`、`face-runtime`。
- 正式 ZIP、微信预览构建和二维码均生成成功。

## 回滚

修改前备份所有涉及文件和本地识别目录；若云端验证失败，恢复备份，不删除本地代码。
