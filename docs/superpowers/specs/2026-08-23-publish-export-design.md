# 去AI标识再导出照片功能设计

## 目标

在微信小程序首页的“制作记录”卡片下面增加“去AI标识再导出照片”入口，让用户把制作记录中的结果图重新绘制并保存到手机相册。

这里的“去 AI 标识”指重新编码图片、清理原图携带的 EXIF/GPS/设备信息等元数据；不对画面中的可见水印做强行擦除，避免破坏人物和背景。

## 页面与入口

- 首页入口位置固定为：`首页 → 制作记录 → 去AI标识再导出照片`。
- 不放到“开始新创作”入口区域。
- 入口使用独立卡片，点击后立即跳转，不等待云端请求。
- 导出页打开时先展示本地缓存的制作记录；云端记录在后台刷新，刷新失败继续使用本地记录。
- 页面顶部增加“1. 导入照片”步骤卡，支持从相册或相机选择手机照片。
- 手机照片只在当前导出页使用，不写入制作记录，也不上传云端；切换到“手机照片”来源后导出。

## 导出流程

1. 读取本地制作记录，默认选中最新一张。
2. 用户可以切换“最新一张”或“全部记录”。
3. 用户可以选择 JPG/PNG、最长边尺寸和 JPG 品质。
4. 可选基础处理：色彩校正、轻度降噪、清晰补偿。
5. 逐张下载或读取原图，用微信 Canvas 重新绘制。
6. 通过 `canvasToTempFilePath` 输出新临时文件，再调用 `saveImageToPhotosAlbum` 保存。
7. 原图不覆盖；过程中展示当前张数和进度，失败时保留已成功保存的图片并提示原因。

## 组件边界

- `pages/publish-export/*`：页面状态、参数选择、记录选择、导出进度和权限提示。
- `utils/publish-export.js`：下载图片、读取尺寸、Canvas 绘制、导出和保存相册的微信 API 封装。
- `pages/workbench/*`：只负责展示入口和跳转。
- `app.json`：注册页面路由。
- `scripts/validate.js`：增加新页面和关键文案的静态检查。

## 错误处理

- 没有制作记录：显示空状态和“先去制作一张图片”的操作提示。
- 图片 URL 失效：提示该记录无法下载，继续处理下一张。
- 相册权限未开启：提示用户打开设置，不反复阻塞页面。
- Canvas 导出失败：停止当前图片，保留已完成结果，并允许重新导出。
- 云端刷新失败：不覆盖本地记录，不影响已经显示的记录。

## 验证标准

- 首页入口出现在制作记录卡片下面。
- 新页面能够从本地缓存立即显示记录。
- 最新一张和全部记录两种模式都能导出。
- JPG/PNG、最长边和 JPG 品质参数能够传到 Canvas 导出流程。
- 生成的新文件保存到相册，原记录不被覆盖。
- 静态校验、兼容性检查、手势 smoke 和正式打包全部通过。
